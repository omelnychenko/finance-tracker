# Finance Tracker

Personal project: receipt photos and voice notes become transactions. A model extracts the fields, code validates them, the user confirms.

## Stack

- Web: Next.js (App Router), React 19, TypeScript, Redux Toolkit, RTK Query, Tailwind
- API: Node.js, Express
- Data: PostgreSQL
- Background jobs: Python, FastAPI, pandas
- Delivery: Docker, GitHub Actions, AWS

## Run

```
cd web
npm install
npm run dev
npm test
```
